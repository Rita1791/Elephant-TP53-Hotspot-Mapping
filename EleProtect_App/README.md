## 🔬 Overview

**EleProtect v2.0** is a computational genomics application developed as a
software component of the **Elephant TP53 Hotspot Mapping** research project.

The application provides an interactive interface for exploring **TP53
hotspot conservation across species** and applying an **exploratory
machine-learning ranking framework** to sequence-derived features.

The application is designed to connect sequence-level computational analysis
with an accessible research interface.
