3. ASIAN ELEPHANT PROTEOME
------------------------------------------------------------

Dataset:
Asian Elephant protein dataset

Source:
NCBI

Assembly:
GCF_024166365.1

Species:
Elephas maximus indicus

Sequence Type:
Protein FASTA

Local Source File:
elephant_proteome.fasta

Approximate File Size:
41 MB

Repository Status:
Not committed to GitHub due to file size.

Purpose:
Used as the target protein database for BLAST analysis.

The dataset was used to identify candidate elephant TP53
sequences and related TP53 retrogene-derived sequences.

Reproducibility:
The source assembly accession and associated NCBI metadata
are retained in this repository so that the corresponding
reference resources can be independently retrieved.

13. DATA ORGANISATION PRINCIPLE
------------------------------------------------------------

Raw database-derived resources are retained separately from
processed comparative datasets.

Raw:
data/raw/

Processed:
data/processed/

Large reference resources are intentionally excluded from
the Git repository when their size makes repository storage
inappropriate.

Accession identifiers, metadata, provenance information, and
retrieval details are retained to support reproducibility.


------------------------------------------------------------
14. REPRODUCIBILITY NOTE
------------------------------------------------------------

Researchers reproducing this analysis should retrieve the
corresponding reference resources using the documented
database accession identifiers and verify sequence versions,
retrieval dates, and analysis parameters before reproducing
downstream results.
