## 🎯 1. Purpose

This document defines how the computational findings of the **Elephant TP53
Hotspot Mapping** project should be interpreted.

The project uses comparative sequence analysis to investigate TP53-related
sequence characteristics between humans and elephants.

The computational workflow includes:

- sequence comparison;
- similarity-based analysis;
- multiple sequence alignment;
- conservation and divergence analysis;
- TP53 mutation-associated position mapping;
- phylogenetic analysis;
- sequence-derived feature analysis; and
- exploratory computational modelling.

The purpose of this document is to clearly distinguish **computational
observations** from **biological conclusions**.
