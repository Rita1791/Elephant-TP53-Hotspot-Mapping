# Artifact Index

## Purpose

This file documents the major research artifacts included in the Elephant TP53 Hotspot Mapping repository.

The goal is to help reviewers quickly understand the purpose of each PDF, figure, notebook, application component, and documentation file.

## Important Interpretation Note

This repository contains computational, sequence-level, and hypothesis-generating research artifacts.

The artifacts do not prove:

- that TP53 alone explains elephant cancer resistance
- that sequence conservation directly explains Peto’s paradox
- that computational observations are equivalent to experimental validation
- that the application component is a clinical tool
